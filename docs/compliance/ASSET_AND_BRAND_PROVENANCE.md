# Asset and brand provenance

## Current UI status

The current Rovyniq website and workspace use only original HTML/CSS composition, original copy, browser/system fonts and text glyphs. There are no downloaded images, stock photos, icon libraries, third-party logos, competitor assets, external web-font requests or model-generated graphics in the published preview.

## Rules for future assets

1. Prefer original code-generated visual elements, commissioned assets with written assignment, or material under a licence approved for the intended commercial use.
2. Record every non-trivial external asset in this document before merge: supplier, file/hash, licence, attribution requirement, permitted channels and retrieval date.
3. Do not use competitor screenshots, trade marks, product copy, layouts, proprietary reports or downloaded app assets as product material.
4. Do not state or imply endorsement by SARS, EasyEquities, TaxTim or any other third party without written authorisation.
5. Legal review is required before using customer testimonials, identifiable people, financial institution marks or data visualisations sourced from third parties.

## Visual system ownership

Rovyniq’s typography fallback stack, navy/emerald/ivory palette, CSS components and written interface language are project-authored. This policy is a control record, not a legal opinion; obtain South African IP counsel review before public commercial launch.
